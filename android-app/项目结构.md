##  下一步操作

### 1. 安装 Android Studio
下载地址：https://developer.android.com/studio

### 2. 打开项目
- 启动 Android Studio
- 选择 "Open an Existing Project"
- 选择 `D:\Python_project\MultiAgent\android-app`

### 3. 修改服务器地址
编辑 `MainActivity.java` 第 34 行：
```java
private static final String SERVER_URL = "http://127.0.0.1:5001";
```
改为您的服务器地址。

### 4. 构建 APK
**方式 A：使用构建脚本**
```bash
双击运行 build-apk.bat
```

**方式 B：使用 Android Studio**
```
Build → Build Bundle(s) / APK(s) → Build APK(s)
```

### 5. 安装到手机
将生成的 APK 文件传输到手机并安装。

##  注意事项

1. **服务器地址**: 默认是本地地址，生产环境需要修改为云服务器地址
2. **HTTPS**: 生产环境建议使用 HTTPS，需要配置 SSL 证书
3. **权限**: 应用会请求多个权限，用户可以选择性授予
4. **网络**: 应用需要网络连接才能使用
5. **文件大小**: 文件上传大小受后端配置限制
