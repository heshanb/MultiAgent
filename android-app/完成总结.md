##  重要配置

### 修改服务器地址
编辑文件：`app/src/main/java/com/multiagent/webview/MainActivity.java`
找到第 34 行：
```java
private static final String SERVER_URL = "http://127.0.0.1:5001";
```
修改为您的服务器地址。

### 本地测试
1. 启动后端：`python main.py`
2. 修改 SERVER_URL 为电脑局域网 IP
3. 确保手机和电脑在同一 WiFi

### 生产环境
1. 部署后端到云服务器
2. 配置 HTTPS 和域名
3. 修改 SERVER_URL 为 HTTPS 地址
4. 构建 Release 版本并签名

##  APK 位置

构建成功后，APK 文件位于：
```
Debug 版本：android-app\app\build\outputs\apk\debug\app-debug.apk
Release 版本：android-app\app\build\outputs\apk\release\app-release.apk
```

##  常见问题

### Q1: 构建失败
- 确保已安装 Android Studio
- 检查网络连接
- 查看构建日志

### Q2: 应用白屏
- 检查后端服务是否运行
- 检查服务器地址
- 检查网络连接

### Q3: 文件上传失败
- 授予存储权限
- 检查后端文件大小限制

### Q4: HTTPS 错误
- 配置 SSL 证书
- 或临时允许混合内容（不推荐）
