# 智能体 Android 应用 - 快速开始

##  3 分钟快速构建 APK

### 方法一：使用构建脚本（最简单）

1. 双击运行 `build-apk.bat`
2. 等待构建完成
3. 在 `app\build\outputs\apk\debug\` 目录找到 APK

### 方法二：使用 Android Studio

1. 用 Android Studio 打开 `android-app` 文件夹
2. 等待 Gradle 同步完成
3. 点击 Build → Build APK
4. 在 `app\build\outputs\apk\debug\` 找到 APK

##  重要配置

### 修改服务器地址

打开 `app\src\main\java\com\multiagent\webview\MainActivity.java`

找到第 34 行：
```java
private static final String SERVER_URL = "http://127.0.0.1:5001";
```

修改为您的服务器地址，例如：
```java
private static final String SERVER_URL = "https://your-server.com";
```

### 本地测试

1. 启动后端服务：
```bash
cd D:\Python_project\MultiAgent
python main.py
```

2. 确保手机和电脑在同一 WiFi 网络
3. 将 SERVER_URL 改为电脑的局域网 IP，例如：
```java
private static final String SERVER_URL = "http://192.168.1.100:5001";
```

##  安装到手机

### 方式 A：USB 调试安装
1. 手机开启开发者选项和 USB 调试
2. 连接手机到电脑
3. 在 Android Studio 中点击 Run 按钮

### 方式 B：直接安装 APK
1. 将 APK 文件传输到手机
2. 在手机上允许"安装未知来源应用"
3. 点击 APK 文件进行安装

##  常见问题

### Q1: 构建失败
- 确保已安装 Android Studio
- 检查网络连接（需要下载依赖）
- 查看构建日志中的错误信息

### Q2: 应用白屏
- 检查后端服务是否运行
- 检查服务器地址是否正确
- 检查手机网络连接

### Q3: 文件上传失败
- 授予应用存储权限
- 检查后端文件大小限制配置
